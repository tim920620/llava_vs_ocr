OCR 輔助下的多模態大型語言模型文字影像理解研究
摘要

近年多模態大型語言模型在視覺問答與影像理解任務上進展快速，但在文字密集型影像上，模型仍常受到文字辨識能力不足的限制。文字密集影像理解近年已被視為獨立且重要的研究方向，相關綜述指出，此類任務涵蓋文件、圖表、網頁、街景招牌與表單等多種場景，對模型的文字辨識、定位與推理能力提出更高要求。另一方面，OCRBench v2 也顯示，當前大型多模態模型在文字定位、手寫內容擷取與視覺文字推理等任務上仍有明顯挑戰。

本研究旨在探討，當多模態大型語言模型結合光學字元辨識技術後，是否能提升文字影像理解表現。研究中將以開源多模態模型 LLaVA 作為核心模型，並結合 PaddleOCR 擷取圖片中的文字資訊，建立一套 OCR 輔助式文字影像理解流程。實驗將以文字密集型資料集進行評估，比較僅使用多模態模型與加入 OCR 輔助後之差異，並以 Accuracy、Exact Match 與 F1 作為主要指標。由於 PaddleOCR 本身即定位為可將圖片與 PDF 轉為可供 AI 使用的結構化資料工具，本研究亦可視為驗證外部文字感知模組對 MLLM 的補強效果。

本研究預期，加入 OCR 結果後，模型在文字密集影像上的理解表現將優於單獨使用多模態大型語言模型的基準方法，尤其在涉及文字讀取、表格內容與圖文結合理解的任務上，改善效果將更為明顯。

一、前言

多模態大型語言模型的發展，使人工智慧系統得以同時處理影像與文字資訊，並在視覺問答、影像描述與跨模態推理中取得良好成果。LLaVA 系列便是代表性開源架構之一，其後續改良版 LLaVA-1.5 透過更強的視覺編碼器與資料設計，在多個基準上建立了更強的開源基線。

然而，這類模型在面對文字密集影像時，常出現辨識不完整、讀錯局部文字、忽略版面結構，甚至答非所問的情況。2025 年的文字密集影像理解綜述指出，MLLM 雖在一般視覺理解上表現突出，但在文件、圖表、網頁與其他 text-rich image 場景中，仍面臨獨特而持續的困難。OCRBench v2 也專門把研究焦點放在大型多模態模型的視覺文字定位與推理能力，並指出現有模型在多項文字相關任務上仍有不足。

因此，本研究聚焦於一個更具可行性且明確的問題：若先以 OCR 擷取圖片中的文字，再將該資訊提供給多模態大型語言模型，是否能提升文字影像理解表現。 此方向相較於同時結合 detector、OCR 與多模態模型的更大系統，實作成本更低，亦更適合作為研討會論文或學生專題的研究主題。

二、研究動機

文字密集型影像理解與一般自然影像理解不同，其核心不只在於辨識場景中的物件，更在於能否正確讀取、對齊並推理圖像中的文字。這包括街景中的招牌、表單中的欄位、圖表中的數值與標籤、以及文件中的段落內容。若模型無法準確取得影像中的文字資訊，即使其語言推理能力再強，也難以在相關任務中給出可靠答案。

OCR 工具在此提供了一種直接而務實的補強方式。PaddleOCR 官方將其定位為能把圖片或 PDF 文件轉換為結構化資料，支援 100 多種語言，並可作為 AI 系統的上游感知模組。對於研討會論文而言，這意味著研究者不必重新設計整個多模態模型，而能以模組化方式驗證：外部文字感知資訊是否能補足 MLLM 的不足。

此外，OCRBench v2 的設計本身也顯示，當前研究社群已不再滿足於只測試模型能否「大致看懂圖片」，而更關注其在文字辨識、定位與文字推理上的細部能力。這使得 OCR 輔助式 MLLM 成為一個兼具研究價值與實作可行性的主題。

三、研究目的

本研究目的如下。

第一，建立一套結合 PaddleOCR 與 LLaVA 的文字影像理解流程，作為 OCR 輔助式多模態理解系統。

第二，比較僅使用多模態大型語言模型與加入 OCR 輔助資訊後的表現差異，以分析 OCR 在文字密集影像任務中的實際貢獻。

第三，以公開資料集進行實驗，透過量化指標驗證 OCR 是否能提升模型在文字影像理解任務上的正確率與整體表現。

四、研究問題

本研究將探討以下問題。

僅使用多模態大型語言模型時，在文字密集型影像任務上的表現如何。
加入 OCR 擷取之文字資訊後，模型整體表現是否提升。
OCR 輔助對哪些題型最有幫助，例如文字讀取、表格理解或圖表問答。
OCR 輔助是否能降低模型因讀字錯誤而造成的回答失準。
五、文獻探討
5.1 多模態大型語言模型

LLaVA 是開源多模態大型語言模型的重要代表。2023 年的原始工作提出以 GPT-4 生成的多模態指令資料進行 visual instruction tuning；2024 年的 LLaVA-1.5 則進一步系統性研究設計選擇，並在 11 個 benchmark 上建立更強的基線。這表示 LLaVA-1.5 很適合作為本研究的核心模型。

5.2 文字密集影像理解

2025 年的綜述將 text-rich image understanding 視為多模態大型語言模型的重要研究分支，指出文件、圖表、網頁、地圖與街景等場景，對模型提出了比一般圖片更複雜的要求。該綜述也說明，文字密集場景中的問題不只包括 OCR 本身，還包括版面理解、文字定位、跨區域資訊整合與語意推理。

5.3 OCR 評測與工具

OCRBench v2 是針對大型多模態模型在視覺文字定位與推理能力上所設計的大型 benchmark。根據其論文，該 benchmark 具有 31 種多樣場景、10,000 組人工驗證的問答對，以及更完整的任務覆蓋範圍。這表明文字相關能力已成為 MLLM 評估中的獨立重點。另一方面，PaddleOCR 作為成熟 OCR 工具，官方明確標示其可將圖片與 PDF 轉為結構化資料，並支援 100 多種語言，適合作為本研究的 OCR 模組。

六、研究方法
6.1 系統架構

本研究採用兩階段流程。

第一階段為 OCR 文字擷取。輸入圖片後，先透過 PaddleOCR 擷取其中可辨識文字，取得文字片段與對應位置資訊。

第二階段為 MLLM 理解與回答。將原始圖片、使用者問題，以及由 OCR 產生的文字結果共同提供給 LLaVA，讓模型根據影像與輔助文字進行回答。LLaVA-1.5 在 Hugging Face 上已有可直接推論的模型格式，適合與自建程式流程整合。

6.2 比較架構

本研究設計兩組比較：

Baseline：MLLM only
只輸入圖片與問題給 LLaVA，不加入 OCR 結果。

Proposed：MLLM + OCR
先以 PaddleOCR 擷取圖片文字，再將 OCR 結果整理成 prompt 或結構化文字，與圖片及問題一同輸入 LLaVA。

6.3 融合方式

本研究採用簡單且可重現的 training-free textual fusion。
也就是不重新訓練模型權重，而是把 OCR 結果轉成文字提示，例如：

OCR results: STOP, speed limit 30, school zone

再連同原始問題一同提供給 LLaVA。這種方式實作簡單，也能清楚觀察 OCR 資訊對結果的影響。

七、資料集與實驗設計
7.1 資料集選擇

本研究建議以 TextVQA、DocVQA 或 ChartQA 之類的文字密集型任務作為主要資料來源。雖然你最終可依資料取得與時間安排擇一，但原則上應選擇需要讀取圖片中文字才能作答的資料集，這樣才能更清楚測試 OCR 輔助的效果。OCRBench v2 所強調的文字定位與推理需求，也支持此類資料集選擇的合理性。

7.2 實驗組與對照組
對照組：MLLM only
實驗組：MLLM + OCR

這樣的設計已足以回答本研究的核心問題：OCR 是否真的能提升文字影像理解。

7.3 評估指標

建議使用以下三項：

Accuracy
Exact Match
F1 Score

若時間足夠，也可補充人工錯誤分析，例如統計哪些錯誤屬於讀字錯誤、答非所問或表格內容誤讀。OCRBench v2 特別強調文字定位與推理能力尚具挑戰，故錯誤分析會讓結果更有說服力。

八、預期結果

本研究預期，在文字密集型影像理解任務中，MLLM + OCR 的表現將優於 MLLM only。原因在於 OCR 能先提供較直接的文字訊息，降低模型僅依靠內部視覺表徵解讀文字時可能產生的誤差。根據 PaddleOCR 的工具定位與 OCRBench v2 所揭示的研究現況，這樣的模組化補強在文字型任務上具有相當合理性。

更具體地說，預期提升將主要出現在需要精確讀字、比對多個文字片段、或綜合圖文資訊回答的題型上。相較之下，對於幾乎不依賴文字訊息的問題，OCR 的幫助可能較有限。

九、研究貢獻

本研究的預期貢獻如下。

第一，提出一個簡單、可重現的 OCR 輔助式多模態文字影像理解流程。

第二，透過實驗比較，驗證 OCR 對開源 MLLM 在文字密集型任務上的補強效果。

第三，為學生專題或小型研討會研究提供一個工作量適中、但具明確研究問題的實作範例。

十、結論

本研究聚焦於 OCR 輔助下的多模態大型語言模型文字影像理解，核心問題在於：當外部 OCR 文字資訊被引入後，模型是否能更有效理解文字密集型影像。根據近年 text-rich image understanding 的研究趨勢、OCRBench v2 的評估設計，以及 PaddleOCR 作為結構化文字擷取工具的定位，此題目兼具研究意義與實作可行性。
